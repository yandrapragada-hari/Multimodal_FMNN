# Interactive Notebooks Guide

This folder contains easy-to-use Jupyter and Google Colab notebooks where you can watch the MM-RFMNN model train, make predictions, and plot graphs step by step.

---

## What is in this Folder?

1. **`MM_RFMNN_Colab_Benchmark.ipynb`**:
   - A clean, ready-to-run interactive notebook.
   - It sets up the environment, generates sample multimodal data, trains the model, and displays interactive charts.
   - You can upload and run this directly in Google Colab without installing anything on your computer.

2. **`MM_RFMNN_Executed.ipynb`**:
   - A pre-run record of the notebook with all outputs, logs, tables, and graphs already saved.
   - You can click on this file right here on GitHub to see the results immediately without running any code.

---

## How to Run in Google Colab (Free & Cloud-Based)

1. Go to [Google Colab](https://colab.research.google.com).
2. Click the **Upload** tab.
3. Select `MM_RFMNN_Colab_Benchmark.ipynb` from this folder.
4. From the top menu, click **Runtime** -> **Run all**.
5. Colab will download the code, train the network, and print all the benchmark tables.

---

## How to Run on Your Local Computer

If you have Jupyter installed on your machine:
```bash
jupyter notebook notebooks/MM_RFMNN_Colab_Benchmark.ipynb
```
